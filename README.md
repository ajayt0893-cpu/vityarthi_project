## 🪨 Rock-Paper-Scissors – Python Game

A simple and fun **Rock-Paper-Scissors** command-line game made using Python.
The user plays against the computer — best of luck beating the AI! 😄

---

### 🚀 Features

✔ Play against the computer
✔ Randomized computer choices
✔ Input validation (accepts only Rock, Paper, or Scissors)
✔ Keeps track of win/lose/draw results

---

### 📌 How to Run the Game

1. Make sure Python is installed (3.x recommended)
2. Download or clone this repository:

```bash
git clone https://github.com/your-username/rock-paper-scissors.git
```

3. Open the project folder:

```bash
cd rock-paper-scissors
```

4. Run the script:

```bash
python game.py
```

---

### 🎮 Gameplay Instructions

* Enter one of the following options:

  ```
  rock
  paper
  scissors
  ```
* The winner is decided using the standard rules:

  * Rock beats Scissors
  * Scissors beats Paper
  * Paper beats Rock
